Quick edit checklist
--------------------
1. Open index.html in a text editor.
2. Replace:
   +91 XXXXX XXXXX
   info@srivijethaschool.in
   "Your school address goes here"
   with the school's real details.
3. Update the About/Learning/Facilities text to match the actual school.
4. If you have campus photos, place them inside assets/ and replace the illustration/cards as desired.

The enquiry form is intentionally static. It displays a confirmation message in the browser.
For real enquiries, connect the form to your preferred email/form service or a small PHP endpoint on cPanel.
